# 커밋 & PR 가이드라인

## 커밋 메시지

커밋 메시지는 자연스러운 한국어로, 간결하게 작성한다.

**형식:** `${type}(${ticket_no}): ${커밋 메시지}`

| type | 사용 시점 |
|---|---|
| feat | 비즈니스 로직 기능 추가/변경 (주석 추가 제외) |
| fix | 비즈니스 로직 오류 수정, 버그 수정 |
| test | 테스트 코드만 변경되거나 테스트가 주 변경사항 |
| refactor | 메인 코드 리팩토링 |
| chore | 주석/어노테이션 추가, 오타 수정, 코드 스타일 적용 |
| docs | 문서 작성 |

`ticket_no`는 `$GIT_BRANCH_NAME`을 참조한다. 브랜치명 형식: `category/ticket_number`

## PR 설명

PR 내용을 아래 형식으로 요약한다. 항목이 여러 개면 `-` 목록으로, 하나면 한 줄로 작성한다.

```markdown
### Note
${변경_요약}

### Commit
${커밋_메시지}
```

예시:
```markdown
### Note
- 변경사항 1
- 변경사항 2

### Commit
- feat(SELL-0001): 커밋 메시지 1
- fix(SELL-0002): 커밋 메시지 2
```
